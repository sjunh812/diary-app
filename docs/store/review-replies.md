# 스토어 리뷰 답글 양식

Play와 App Store 리뷰에 답할 때 쓰는 한국어 양식이다(사용자 검토 2026-11-15).

## 쓰는 법

- 첫 줄은 "안녕하세요, 1일 1일기입니다."로 연다. 본문은 해요체다.
- 이모지는 감사·칭찬 답에만 하나 넣는다. 사과하는 답에는 넣지 않는다.
- Play 답글은 350자까지다. 앞으로 나올 기능은 약속하지 않는다.
- 메뉴 이름은 앱 화면 문구와 같다: 설정 > 의견 보내기, 설정 > 백업과 복원, 광고만 없애기. 화면 문구가 바뀌면 여기도 고친다.
- 일기·사진이 사라졌다는 리뷰는 답글에서 해결하려 하지 않고 의견 보내기로 안내한다.
- 리뷰 속 일기 내용이나 개인정보를 답글에 옮겨 적지 않는다.

## 1. 칭찬

```text
안녕하세요, 1일 1일기입니다.
따뜻한 리뷰 감사해요 😊

하루를 짧게라도 남기는 데 도움이 되었다니 정말 기뻐요.
앞으로도 편하게 쓰실 수 있게 꾸준히 업데이트할게요.
```

## 2. 기능 요청

```text
안녕하세요, 1일 1일기입니다.
좋은 의견 감사해요 🙌

보내주신 내용은 잘 모아두었다가
다음 업데이트를 정할 때 꼼꼼히 살펴볼게요.
```

## 3. 오류·불편 신고

```text
안녕하세요, 1일 1일기입니다.
불편을 드려 죄송해요.

어떤 기기에서, 어느 화면에서 생기는지
설정 > 의견 보내기로 알려주시면 빠르게 확인할게요.
```

## 4. 고친 뒤 다시 답할 때

버전 번호는 고친 버전으로 바꾼다.

```text
안녕하세요, 1일 1일기입니다.
2.0.1 버전에서 고쳤어요.

업데이트한 뒤에도 같은 문제가 있으면
설정 > 의견 보내기로 알려주세요.

알려주셔서 감사해요.
```

## 5. 일기·사진이 사라졌어요

가장 먼저 답한다.

```text
안녕하세요, 1일 1일기입니다.
많이 놀라셨을 것 같아 정말 죄송해요.

업데이트할 때 예전 일기는 지우지 않고 그대로 두도록 만들었어요.
설정 > 의견 보내기로 연락 주시면 함께 찾아드릴게요.
```

## 6. 광고가 불편해요

```text
안녕하세요, 1일 1일기입니다.
불편을 드려 죄송해요.

일기를 쓰고 읽는 화면 안에는 광고를 넣지 않아요.
전면 광고는 하루 한 번, 일기를 저장한 뒤에만 잠깐 나와요.

광고가 불편하시면 '광고만 없애기'(1회 구매)가 있어요.
짧은 영상을 보면 24시간 동안 광고 없이 쓸 수도 있어요.
```

## 7. 유료로 바뀌었나요?

```text
안녕하세요, 1일 1일기입니다.
걱정하지 않으셔도 돼요.

원래 쓰시던 기능과 사진 포함 백업은 계속 무료예요.
Plus는 한 편에 사진 30장, 체크리스트, 고급 통계를 원하시는 분을 위한 선택이에요.
```

## 8. 백업·복원 문의

```text
안녕하세요, 1일 1일기입니다.
문의 감사해요 😊

설정 > 백업과 복원에서 구글 드라이브를 연결하면 사진까지 백업돼요.
예전 버전에서 올린 백업도 같은 화면에서 불러올 수 있어요.

잘 안되면 설정 > 의견 보내기로 알려주세요.
```

## 9. 별점만 낮고 이유가 없을 때

```text
안녕하세요, 1일 1일기입니다.
불편을 드려 죄송해요.

어떤 점이 아쉬우셨는지 설정 > 의견 보내기로 알려주시면
꼼꼼히 살펴볼게요.
```
