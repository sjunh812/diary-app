# 프로토타입: 앱 테마 색

Figma "프로토타입 · 시안" 페이지 > "프로토타입" > **"프로토타입 · 테마 색"**. 흐름 시작 5개에서 눌러 본다. 고른 안만 "시안 · 테마 색"에 남겼다. 고르지 않은 안과 지난 판은 2026-11-22에 지웠다.

상태: **확정**(2026-11-22 사용자 확정).

## 화면 규칙

- 정한 색 7가지(라벤더·자두·로즈·단풍·숲·바다·흑백)와 직접 고르기, 2줄×4칸 8칸. 프로토타입 화면은 확정 때 색(노을·꿀·숲·바다)이라 2026-11-22에 바꾼 묶음은 "시안 · 테마 색 > 파스텔 묶음 + 검정/진회색 vs M1"과 Figma "화면" 페이지를 본다.
- 무료에게만 직접 고르기 원 오른쪽 위에 Plus 칩(고른 테마의 `selected` 바탕, `accentText` 글자).
- 견본·그림을 누르면 바로 저장되고 앱 전체가 바뀐다. 직접 고르기만 [이 색으로 하기]에서 바뀐다.
- 예시 직접 색은 라즈베리 `#C2185B`(흰 글자 5.9:1).

## 확인할 것

- 흐름과 화면 수가 맞는지.
- Plus 안내 시트 제목은 두 줄로 끊었다("테마 색 직접 고르기는 / Plus에서 쓸 수 있어요"). 개발에서는 낱말 단위 줄바꿈을 쓴다.
