## 프로토타입과 견주기

2026-11-22. 확정 프로토타입(A1~A6, B0~B4, C1~C3, D1)과 "화면" 페이지를 나란히 봤다. 흐름과 배치는 같다. 바뀐 것은 Plus 칩이 부품이 된 것과 결제 화면 그림이 자르는 방식뿐이라 다시 확인받지 않는다.

## 에뮬레이터에서 본 것

Pixel 계열 에뮬레이터(Android 12, 1080×2400), 한국어, 손글씨 글꼴(힘내라는 말보단), 개발 빌드.

- 무료: 설정 > 테마 → 바다 → 다크 그림 → 직접 고르기 → Plus 안내 시트 → 결제 화면(핵심 넷).
- Plus(개발자 모드): 직접 고르기 시트에서 색을 골라 [이 색으로 하기] → 앱 전체와 설정 줄 "직접 고른 색 · 다크".
- 무료로 되돌리면 직접 고른 색을 지우고 라벤더로 되돌린다. 직접 고르기 칸은 빈 칸에 Plus 칩이다(2026-11-22 사용자 결정).
- 처음 눌렀을 때 개발 빌드가 꺼졌다. 통계 이름표에 새 설정 이름이 없어 엄격 모드가 막았다. 허용 목록에 넣고 화면 모델 시험을 더했다.
