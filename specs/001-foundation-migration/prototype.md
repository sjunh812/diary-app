# Prototype: 기반과 이전

`/diary-flow` 3단계 기록이다. 프로토타입은 Figma "1일 1일기"(`HQOqmp9kJv5EEpQH2mXMj9`)의 "표지 · 흐름" 페이지, 섹션 "프로토타입 · 기반과 이전"에 있다.
프레젠테이션 보기로 눌러 본다. 목적은 흐름을 눌러 보고 고치는 것이고, 색·글자·크기는 확정한 디자인 시스템(`docs/design.md`) 변수와 글자 스타일을 쓴다.
다듬는 것은 4단계에서 한다.

상태: **확정**(2026-11-01 사용자 확인). 화면 28장, 연결 90개(H1이 이어받은 스펙 002 홈 연결 포함), 흐름 시작점 다섯.

확정 전에 바뀐 점:

- 문구를 한국어 스킬 기준으로 다듬었다. 권한은 "허용", 기기는 "휴대폰", 예전 버전은 "예전 앱"으로 맞추고("허락하기" → "허용하기",
  "남은 기회" → "남은 횟수", "0:27 뒤" → "27초 뒤", "옛 일기 읽기" → "예전 일기 보기"), 저장 공간 화면은 휴대폰 공간임을 제목에서 밝혔다
  ("휴대폰 저장 공간이 부족해요").
- 화면 모드의 "시스템 설정 따르기"를 "시스템 설정"으로 줄였다(설정 목록 값과 같은 말).
- 잠금 설정의 다시 잠그기 안내를 "돌아왔을 때 고른 시간이 지났으면"으로 고쳤다(맞춤법 검사기 지적: "이 시간이"의 "이"가 조사로 읽힘).
- 글꼴 화면(G1) 목록을 다시 고른 10종으로 바꿨다(`docs/design.md` 일기 본문 글꼴).
- 업데이트한 사용자는 이전 결과 뒤에 개발자의 편지와 온보딩을 보고(스펙 004), 이 프로토타입은 M2에서 홈으로 바로 잇는다.

확정 뒤 바뀐 점(2026-11-01): "기록 이전 결과"는 일부만 옮겨진 기기에서만 설정에 보이고 다시 시도 버튼이 없어졌다(앱 업데이트 뒤 자동으로 한 번 더 읽음).
S6 설정 목록에서 그 줄을 빼고, M5를 "M5 기록 이전 결과 · 일부만"(읽지 못한 일기 12편, 원본 파일 내보내기, 문의하기)으로 바꿨다. "화면" 페이지는 tasks T091.

확정 뒤 바뀐 점(2026-11-03, 사용자 결정): R1 매일 알림의 "알림 시각" 줄을 누르면 바텀 시트에 오전·오후 / 시 / 분 휠이 뜨고 "저장"으로 바꾼다.
알림을 끄면 알림 시각 줄을 숨긴다. G1 글꼴 목록의 줄 이름은 그 글꼴로 그린다(받기 전 글꼴은 이름 그림). "화면" 페이지 "매일 알림 상태"와 "글꼴 (G1)"에 그렸다.
M5의 문의하기는 "M5 · 복구 문의" 시트로 간다("깨진 일기를 고쳐 드릴 수 있어요", 들어 있는 것과 지우는 때, [첨부 없이 문의] [첨부해서 문의], FR-010a).

## 근거

- 흐름 순서와 화면 상태는 `contracts/app-shell.md`(시작 순서), `contracts/migration-flow.md`(이전 화면 상태), `contracts/lock.md`(잠금 규칙)를 따른다.
- 잠금 화면: 4칸 점과 숫자판, 생체 인증 버튼, "비밀번호를 잊어버렸어요"는 Day One·Daylio 잠금과 같은 구성이다(스펙 근거 절). 비밀번호를 잊으면 폰 화면 잠금으로
  확인한다(스펙 Clarifications).
- 이전 화면: 시작 화면과 따로 진행 화면을 둔다(Android Splash screen 문서는 작은 데이터만 붙잡으라고 한다, 스펙 근거 절). 진행 화면에는 개수만 보이고
  일기 내용과 사진은 없다(FR-008).
- 설정: 스펙 002 프로토타입의 "S6 설정"(확정) 모양을 잇는다. 본문 글자 크기는 Day One "entries only"처럼 일기 본문에만 걸린다(research R17).

## 흐름

시작점 다섯이다.

| 시작점 | 지나가는 화면 |
| --- | --- |
| 기반과 이전 · 업데이트(잠금 켬) | SP(0.8초) → L1 잠금 · 생체 인증 → 지문 누르면 M1, "비밀번호 입력"이면 L1 잠금 → 숫자 → M1 이전 중(1.8초) → M2 다 옮겼어요 → H1 홈 · 글꼴이 바뀌었어요 → 토스트 "바꾸기" → G1 |
| 기반과 이전 · 업데이트(잠금 없음) | M0 이전 준비(1.2초) → M1 이전 중 → M2 다 옮겼어요 → H1 |
| 기반과 이전 · 옮기지 못함 | M3 옮기지 못했어요 → 예전 일기 보기 M4(뒤로 M3) / 원본 파일 내보내기 M4 · 원본을 저장했어요 / 다시 시도 → M1 |
| 기반과 이전 · 비밀번호 잊음 | L1 · 비밀번호가 맞지 않아요 → 숫자 → L1 · 잠시 기다려 주세요 → 비밀번호를 잊어버렸어요 → L3 → 확인하기(폰 잠금 확인은 시스템 창이라 생략) → L2 새 비밀번호 → L2 · 한 번 더 → S1 홈. L3 시트 제목을 누르면 L3 · 폰 잠금이 없어요 |
| 기반과 이전 · 설정 | S6 설정 · 이전한 기기 → 글꼴 G1, 본문 글자 크기 G2, 화면 모드 G3, 잠금 L4(비밀번호 바꾸기 → L2), 매일 알림 R1, 기록 이전 결과 M5(각각 뒤로 → S6). 탭은 스펙 002 홈·달력·돌아보기로 |

뒤로 가기:

- 잠금(L1)과 이전(M0~M3)은 관문이라 뒤로 가기로 벗어나지 않는다. 잠금 화면에서 뒤로는 앱을 닫는다.
- M4 예전 일기 보기에서 뒤로는 M3로, L2에서 뒤로는 L1로 간다.
- 설정 하위 화면은 뒤로 → S6.

## 상태와 문구 원칙

- 진행 화면은 "일기 n / N편", "사진 n / N장"만 보이고 0.25초마다 바뀐다(`contracts/migration-flow.md`).
- 실패 화면 첫 문장은 무엇이 안 됐는지, 둘째 문장은 "원래 기록은 그대로 있어요"다(헌법 I을 사용자 말로).
- 잠금 문구는 탓하지 않는다: "비밀번호가 맞지 않아요", "잠시 기다려 주세요".
- 낱말은 플랫폼과 맞춘다: 권한은 "허용"(Android·iOS 권한 창의 말), 기기는 "휴대폰", 예전 버전은 "예전 앱".
- 한국어 문구는 `korean-humanizer` 기준으로 다듬고 `korean-spell-check`로 검수한다(2026-11-01 사용자 요청). 2026-11-01 검수는 맞춤법 검사기가 403으로 막혀 휴머나이저 기준으로만 했다.
- 시작 화면은 움직임 없이 가운데 연필만(`docs/design.md` 앱 아이콘과 스플래시).
- 화면 문구의 원본은 코드의 문자열 리소스다. 이 문구는 초안이고 개발 때 리소스로 옮기며 다듬는다.
