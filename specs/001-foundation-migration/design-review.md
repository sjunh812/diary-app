# 디자인 점검: 기반과 이전 (T093)

개발 전에 Figma "1일 1일기"의 "디자인 시스템" 페이지와 "화면" 페이지 001 15줄(T091 반영 뒤)을 레퍼런스 디자인 시스템에 대어 봤다
(사용자 요청 2026-11-01, 헌법 V, `docs/design.md` "개발 전 디자인 점검"). 점검일 2026-11-01.

## 본 방법

- Figma 값은 플러그인으로 뽑았다. 대상은 001 화면의 라이트 프레임 27장(상태 섹션 포함)이고, 고칠 때는 다크·태블릿까지 같이 고쳤다.
  - 글자: 글자 스타일에 묶였는지, 묶이지 않았으면 크기·굵기
  - 색: 변수에 묶였는지, 글자색 변수의 대비(WCAG 2.x 식으로 계산)
  - 크기: 모서리 값, 자동 배치 여백·간격, 아이콘 크기, 누르는 것의 보이는 크기
- 레퍼런스 수치는 1차 자료에서만 가져왔다.
  - TDS: `@toss/tds-mobile@2.5.1` `dist/esm/index.js`
  - SEED: `@seed-design/css@3.1.0` `recipes/*.css`, github.com/daangn/seed-design `packages/rootage/components/*.yaml`(dev 브랜치)
  - M3: androidx `compose/material3/.../tokens/*.kt`
  - HIG: developer.apple.com/design/human-interface-guidelines
  - 내려받은 원본은 실행하지 않고 글자로만 읽었다. 찾지 못한 값은 "확인 못 함"으로 적었다.
