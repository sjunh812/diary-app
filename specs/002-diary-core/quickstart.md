# Quickstart: 일기 핵심 화면 확인

스펙 001이 프로젝트 뼈대를 만든 뒤에 쓰는 확인 안내다. 모듈 경로와 명령은 001이 `CLAUDE.md` "빌드와 시험"에 채운 것을 따른다.

## 준비

- 에뮬레이터: 폰(폭 411dp), 폴더블(접힘·펼침), 태블릿(폭 1280dp). 설치는 에뮬레이터에만(`ANDROID_SERIAL` 지정).
- iOS 시뮬레이터: iPhone, iPad(R2 출시 전이라도 공유 코드 확인용).
- 시험 데이터: 001의 레거시 고정 DB(1만 편, 사진 5천 장, 사진 한도 초과 일기, MISSING 사진 포함)로 이전한 상태.

## 자동 시험

```bash
./gradlew testAndroidHostTest
```

```bash
./gradlew iosSimulatorArm64Test
```

지켜야 하는 시험(이름은 tasks.md에서 정한다):

- 서식 정리: 허용 목록 밖 태그·속성·색이 버려지고 글은 남는다(`contracts/rich-text-html.md`).
- `toPlainText(레거시 변환(원문)) == 원문`.
- 임시 저장: 입력 → 1초 뒤 Draft, 프로세스 재시작 뒤 복원, `commit` 실패 시 Draft 유지.
- 사진: 한도 10/30, 한도 넘은 이전 일기는 더하기만 막힘, 축소 뒤 긴 변 2,560 이하, 같은 사진 두 번이면 파일 하나.
- 휴지통: 지우면 모든 질의에서 빠짐, 되돌리기, 30일 지난 것만 비움, 쓰지 않는 사진만 정리.
- 검색: 한 글자 한국어, `%`·`_` 입력, 조건 조합, 통계 → 검색 결과 일치.
- 통계: 기간 경계(주 시작 요일, 월말, 윤년), 기분 없음 개수, 동점.
- 로그·분석 이벤트에 본문·장소가 없는지(헌법 II).

## 손으로 확인

| 이야기 | 해 볼 것 | 기대 |
| --- | --- | --- |
| US1 | 쓰기 열기 → 글만 쓰고 저장 | 저장됨, 상세로 이동, "저장했어요" |
| US1 | 쓰는 중 최근 앱에서 앱 강제 종료 → 다시 쓰기 | "쓰던 일기가 있어요", 글·서식·사진 그대로 |
| US1 | 사진 12장 고르기(무료) | 10장까지만 고를 수 있음, 한도 안내 한 줄 |
| US1 | 날짜를 어제로 | 자동 채운 날씨가 지워짐 |
| US2 | 홈 훑기, 즐겨찾기만, 다른 달로, 사진 중심 보기 | 레거시와 같은 기능이 모두 됨 |
| US3 | 하루 2편인 날, 빈 날 누르기 | 편수 표시, [이날 일기 쓰기] |
| US4 | "밥", 장소 이름, 기분+기간 | 결과와 강조 |
| US5 | 월 통계 이전 달로, 기분 누르기 | 그 기분 일기 목록 |
| US6 | 지우기 → 되돌리기, 휴지통 되살리기·완전히 지우기 | 확인 창은 영구 삭제 때만 |
| US7 | 태블릿 홈·달력·쓰기, 폴더블 접기·펼치기, Ctrl+N/S/F | 두 칸, 상태 유지, 단축키 |
| 공통 | 다크 모드, 글꼴 200%, TalkBack/VoiceOver | 잘림·겹침 없음, 읽기 순서 자연스러움 |
