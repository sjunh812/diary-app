# 화면 전환 계약

화면 키와 뒤로 가기, 창 폭별 배치를 정한다. 키는 `shared/app`이 갖고 기능 모듈은 진입 컴포저블만 내놓는다.

## 화면 키

| 키 | 화면 | 인자 |
| --- | --- | --- |
| `Home` | 홈 목록 (S1) | 없음 |
| `EntryDetail(entryId)` | 상세 (S3) | 일기 ID |
| `PhotoViewer(entryId, index)` | 사진 크게 (S3-a) | |
| `Write(target)` | 쓰기·고치기 (S2) | `New(date?)` 또는 `Edit(entryId)` |
| `Calendar(yearMonth?)` | 달력 (S4) | |
| `Search(filter?)` | 검색 (S1-a) | 통계에서 오면 조건이 채워져 있다 |
| `Insight` | 기분 통계 (S5) | |
| `Trash` | 휴지통 (S6-7) | |

하단 탭(폰)과 레일(600dp 이상)의 항목은 홈, 달력, 돌아보기(통계), 설정 넷이고 쓰기 버튼은 늘 보인다. 레거시는 쓰기가 탭이었다.

## 뒤로 가기

- 탭 안 화면에서 뒤로 가면 그 탭의 첫 화면, 첫 화면에서 뒤로 가면 홈, 홈에서 뒤로 가면 앱을 닫는다(Android 시스템 기본, 레거시의 "두 번 눌러 종료"는 쓰지 않는다).
- 쓰기에서 뒤로 가면 임시 저장 뒤 들어온 곳으로(FR-011).
- 검색 → 상세 → 뒤로 가면 검색 화면이 입력·조건·스크롤 그대로(FR-027).

## 창 폭별 배치

| 폭 | 홈 | 달력 | 쓰기 |
| --- | --- | --- | --- |
| 600dp 미만 | `Home` 한 칸, 줄을 누르면 `EntryDetail`로 쌓임 | 달력 아래 그날 목록 | 전체 화면 |
| 600~839dp | 위와 같고 레일 | 위와 같고 레일 | 전체 화면 |
| 840dp 이상 | `Home` 왼쪽 + `EntryDetail` 오른쪽(고른 게 없으면 안내) | 달력 왼쪽 + 그날 목록 오른쪽 | 본문 가운데 + 옆 칸(기분·날씨·장소·사진) |

- 두 칸에서 고른 상세는 뒤로 쌓지 않고 오른쪽만 바꾼다. 폭이 좁아지면 그 상세가 한 칸으로 쌓인 상태로 바뀐다(FR-037).
- 두 칸에서 상세를 지우면 오른쪽은 안내 문구로 돌아간다.
