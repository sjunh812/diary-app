# 스펙 002 디자인 점검

화면을 개발로 넘기기 전에 Figma를 레퍼런스에 대어 본 기록이다(`docs/design.md` "개발 전 디자인 점검").

## 2026-11-04 홈(S1), 일기 상세(S3)

- 본 것: 여백(상자 여백, 홈 백업 줄, 일기 줄), 글자 크기·굵기, 다크 색, 넓은 화면.
- 레퍼런스: 일기 줄과 달 머리는 `docs/design.md`의 Apple 저널·Day One 근거를 따른다. 상세 더보기는 토스처럼 떠 있는 시트다.
- 여백: 큰 제목 → 백업 줄 4, 백업 줄 → 첫 일기 12, 줄 왼쪽은 큰 제목 선에 맞췄다. 상자가 있는 화면은 상자 여백 규칙을 쓴다.
- 고친 것: 다크 상세에서 서식이 섞인 본문의 색 변수가 바뀌지 않아 글자가 안 보이던 것.
- 확인 못 한 것: 토스·당근의 일기 목록에 해당하는 화면 수치는 공식 자료에서 찾지 못했다.

## 2026-11-04 쓰기(S2)

- 구조는 확정 프로토타입 그대로다(위 줄, 첨부 칩, 사진 줄, 본문, 서식 도구 줄). 글자색은 도구 줄이 팔레트로 바뀌는 Apple 저널 방식이다.
- 고친 것: "쓰던 일기" 시트의 인용 상자 안쪽을 16으로 맞췄다.

## 2026-11-04 달력(S4), 찾기(S1-a), 돌아보기(S5), 휴지통(S6-7)

- 구조는 확정 프로토타입 그대로다.
- 고친 것: 달력 격자와 그날 일기 목록 사이를 12로 맞췄다.
- 남은 것: 찾기, 돌아보기, 휴지통의 태블릿 화면은 프로토타입에 틀이 없다. 개발 전 점검(T076)에서 맞춘다.

## 2026-11-04 전체 점검 (T076)

Figma "화면" 페이지의 002 13개 섹션을 플러그인으로 쟀다. 기준은 스펙 001 점검과 같은 1차 자료다(TDS, SEED, M3, HIG, WCAG). 색 대비는 코드 토큰으로 계산했다.

| 본 것 | 잰 값 | 판단 | 고친 곳 |
| --- | --- | --- | --- |
| 넓은 화면 틀 | 찾기, 돌아보기, 휴지통에 태블릿이 없었다 | 고침: 헌법 VI. 폰을 늘리지 않고 이미 있는 규칙을 쓴다 | 찾기는 목록 360 + 상세, 돌아보기는 가운데 680 한 칸, 휴지통은 설정 + 옆 칸 |
| 글자 크기 | 12·13·14·15·17·20·22·28, 모두 글자 스타일 | 그대로. 묶이지 않은 것은 사진 크게 화면의 시각·쪽수 두 곳이고 사진 위 글이다 | - |
| 백업 줄 색 | `textTertiary` 3.4:1 | 고침: 마지막 백업 시각은 꼭 봐야 하는 정보다. WCAG 1.4.3 본문 4.5:1 | `textSecondary`(6.6:1), `docs/design.md`, Figma 45곳 |
| 그 밖의 글자 대비 | `textSecondary` 라이트 5.4~6.6, `accentText` 5.0~6.2, `danger` 4.2~5.2 | `danger`는 `selected` 위에서 4.5 아래지만 그 자리에 쓰지 않는다 | - |
| `textTertiary` 쓰임 | 비활성 탭과 가운뎃점 | 규칙대로 | - |
| 입력 안내 | `placeholder` 라이트 2.1:1 | 그대로: 필요한 정보를 싣지 않는 안내 글이다 | - |
| 다크 `accent` | 바탕에서 3.3:1 | 그대로: 면이라 WCAG 1.4.11 3:1을 넘고, 위 글자는 5.4:1 | - |
| 아이콘 크기 | 16·20·24, 쓰기 사진 지우기 12, 결과 32 | 규칙대로 | - |
| 아이콘 선 | 16에서 1.5(규칙은 비례해서 1.17) | 고침: 코드는 24 기준으로 줄여 그린다. Figma만 굵었다 | 세 페이지의 16 아이콘 전부 |
| 터치 영역 | 찾기 지우기 18, 토스트 되돌리기 22 높이, 달력 "이날 일기 쓰기" 38 | 보이는 크기는 그대로 두고 코드에서 넓힌다(M3 48, `docs/design.md` "터치 영역") | 개발 |
| 묶이지 않은 칠 | 모두 사진 자리 그림 | 그대로 | - |
| 문구 | 찾기 태블릿 날씨 이름 | "구름 조금"으로 스펙 FR-003 이름을 따랐다 | - |

화면 구조는 확정 프로토타입 그대로라 기존 사용자가 길을 잃는 변경은 없다.
토스·당근의 일기 목록, 달력, 통계 화면 수치는 공식 자료에서 찾지 못해 대지 못했다.
