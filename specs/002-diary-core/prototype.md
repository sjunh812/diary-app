# Prototype: 일기 핵심 화면

`/diary-flow` 3단계 기록이다. 프로토타입은 Figma "1일 1일기"(`HQOqmp9kJv5EEpQH2mXMj9`)의 "표지 · 흐름" 페이지, 섹션 "프로토타입 · 일기 핵심"에 있다
(사용자 결정 2026-10-31, HTML 대신 Figma). 프레젠테이션 보기로 눌러 본다. 목적은 흐름을 눌러 보고 고치는 것이다. 색·글자·크기는 확정된 디자인 시스템(`docs/design.md`, D6)을 쓴다. 다듬는 것은 4단계에서 한다.

상태: **확정**(2026-10-31, 사용자 확인). 화면 32장, 연결 87개, 흐름 시작점 셋("일기 핵심 · 폰", "일기 핵심 · 첫 사용(빈 상태)",
"일기 핵심 · 태블릿"). 첫 판은 디자인 시스템 확정 전에 그려 지웠고, 최종 점검한 디자인 시스템(변수·글자 스타일)으로 다시 그렸다.

## Figma 화면

섹션 안에 이야기별로 다섯 줄이다. 프레임 이름이 화면 ID다.

| 줄 | 프레임 |
| --- | --- |
| 1. 홈·상세 | S1 홈, S1 홈 · 빈 상태, S1 · 연·월 고르기, S3 상세, S3 · 더보기, S3-a 사진 크게, S1 · 휴지통으로 옮겼어요 |
| 2. 쓰기 | S2 쓰기 · 새 일기, S2 · 기분·날씨, S2 쓰기 · 쓰는 중, S2 · 글자색, S2 · 사진 한도, S1 · 임시 저장했어요, S2 · 쓰던 일기, S3 · 저장했어요 |
| 3. 달력·찾기 | S4 달력, S4 · 빈 날, S1-a 찾기, S1-a · 결과 없음 |
| 4. 돌아보기·설정·휴지통 | S5 돌아보기, S6 설정, S6-7 휴지통, S6-7 · 고르기, S6-7 · 지우기 확인, S6-7 · 비우기 확인, S6-7 · 빈 상태 |
| 5. 넓은 화면(1194×834) | T1 홈 · 목록\|상세, T2 달력 · 격자\|그날, T3 쓰기 · 본문\|옆 칸 |

프로토타입에서 정한 배치:

- 상세의 [더보기]는 메뉴 대신 떠 있는 시트(공유하기, 휴지통으로 옮기기)다. 토스처럼 동작 목록은 시트로 낸다.
- 쓰기: 위에 닫기(×, 임시 저장 뒤 나감), 날짜 단추, 글자 버튼 [저장](글·사진·기분이 없으면 흐리게, FR-002). 채운 보라 버튼은 상단 바에서
  뜬 것처럼 보여 글자 버튼으로 바꿨다(사용자 지적). 그 아래 첨부 칩(기분, 날씨, 장소), 사진 줄(72, 빼기 ×, 남은 장수), 본문, 아래
  서식 도구 한 줄(사진, 카메라, 굵게, 밑줄, 글자색, 형광펜, 목록, 체크리스트). 글자색을 누르면 도구 줄이 팔레트 줄로 바뀐다(Apple 저널).
- 사진 한도에 닿으면 사진 줄 아래 한 줄 안내와 [Plus 보기]. 저장은 막지 않는다(FR-006).
- 달력: 오늘은 날짜 숫자에 보라 원, 하루 여러 편은 얼굴 뒤에 앞 일기의 기분 색을 겹치고, 기분 없는 일기는 회색 원 안 글줄(2026-11-05), 일요일 빨강·토요일 파랑. 고른 날은 연보라 칸.
- 찾기: 결과를 달 머리로 묶고 찾은 글자를 보라로 강조한다.
- 돌아보기: 주·월·년·전체 탭, 기간 넘기기, 해요체 요약 한 줄, 기분 막대(많은 순).
- 휴지통: 위에 "30일 뒤에 완전히 사라져요" 안내, 줄마다 남은 날(1일 남음은 빨강), [비우기]는 편수를 보여 주고 묻는다.

## 이야기별 지나가는 화면

| 이야기 | 흐름 |
| --- | --- |
| US1 쓰기 | 아무 화면 → [쓰기] → S2 쓰기(날짜·시각, 본문, 서식 도구, 첨부 칩) → 기분·날씨 시트 → 사진 고르기 → [저장] → S3 상세("저장했어요") |
| US1 임시 저장 | S2에서 글 쓰기 → 뒤로 → 들어온 화면("임시 저장했어요") → [쓰기] → "쓰던 일기가 있어요" [이어 쓰기]/[새로 쓰기] |
| US2 목록·상세 | S1 홈 → 줄 → S3 상세 → 사진 → S3-a 사진 크게 / S3 [수정하기] → S2 / S1 달 머리 → 연·월 시트 |
| US3 달력 | S4 달력 → 일기 있는 날 → 그날 목록 → S3 / 빈 날 → [이날 일기 쓰기] → S2(그 날짜) |
| US4 찾기 | S1 [찾기] → S1-a 검색 → 칩 고르기 → 결과 → S3 → 뒤로(입력·조건 유지) |
| US5 통계 | S5 돌아보기 → 기간 전환·이전 → 기분 막대 누르기 → S1-a(기분·기간 조건 채워짐) |
| US6 휴지통 | S3 [지우기] → S1("휴지통으로 옮겼어요 [되돌리기]") / S6 설정 → S6-7 휴지통 → [복원하기]·[완전히 삭제하기](확인) |
| US7 넓은 화면 | 폭 전환 → 레일 + S1|S3 두 칸, S4|그날 목록 두 칸, S2 본문 + 옆 칸 |

## 뒤로 가기

`contracts/navigation.md`를 따른다. 쓰기에서 뒤로 가면 임시 저장 뒤 들어온 곳, 검색 → 상세 → 뒤로는 검색 그대로.

## 상태 목록 (빠뜨리지 않기)

- 홈: 일기 없음, 즐겨찾기 없음, 목록 보기(피드·카드·사진 격자)
- 쓰기: 새 일기, 수정, 쓰던 일기 있음, 사진 한도(10장), 위치 권한 없음(장소 시트 안내), 위치 꺼짐, 위치 찾기 실패
- 상세: 사진 없음, 찾을 수 없는 사진(MISSING), 서식 있는 본문
- 달력: 하루 2편, 기분 없는 날, 빈 날
- 검색: 결과 없음, 조건만
- 통계: 기간에 일기 없음, 기분 없는 일기만
- 휴지통: 비었음, 곧 지워짐(1일 남음)
- 공통: 첫 실행(이전 결과에서 넘어옴은 스펙 004), 다크 모드

## 바뀐 점

- 2026-10-31 확정. 스펙에 되먹인 것: 목록 모양 피드·카드·사진 격자(FR-018), 되돌리기 알림 5초와 누르는 동안 멈춤(research O5).
- 상단 바의 [저장]을 채운 버튼에서 글자 버튼으로 바꿨다(사용자 지적, `docs/design.md` 상단 바).
- 달력 숫자 뱃지가 잘리지 않게 칸 바탕색 테두리를 둘렀다(사용자 지적).
- 상세 [더보기]는 메뉴 대신 시트, 쓰기 서식 도구의 글자색은 팔레트 줄로 바뀌는 방식으로 정했다.
