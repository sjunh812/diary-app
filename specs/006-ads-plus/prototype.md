# 프로토타입: 광고와 Plus

Figma "화면" 페이지 섹션 "Plus와 광고 (P1~P7)". 문구의 원본은 코드의 문자열 리소스다.

| 화면 | 들어오는 길 | 나가는 길 |
| --- | --- | --- |
| P1 결제 화면 | 설정 초대 카드, P3, 무료의 고급 통계 칸 | 닫기는 온 곳으로, 구매하면 P4, [광고만 없애기]는 P2 |
| P2 광고 제거 시트 | 광고 오른쪽 위 ×, P1의 [광고만 없애기] | 구매, 닫기, 또는 "영상 보고 하루만 없애기"로 P7 |
| P3 사진 한도 시트 | 사진 11장째 | [Plus 알아보기]는 P1, [괜찮아요]는 쓰기 그대로 |
| P4 Plus 관리 | 이미 Plus일 때 설정 초대 카드 | 스토어 구독 관리, 뒤로. 혜택, 요금, 구독 관리, 끊어도 기록이 남는다는 안내 |
| P5 홈 광고 자리 | 무료의 홈 목록. 얇은 줄과 카드를 번갈아 쓴다 | 광고를 누르면 광고주 페이지, ×는 P2 |
| P6 돌아보기 입구 | 돌아보기 위 줄의 작은 버튼 | 무료는 P1, Plus는 P8 |
| P7 보상형 시트 | P2의 "영상 보고 하루만 없애기" | 영상을 보면 24시간 광고 없음 |
| P9 체크리스트 Plus 시트 | 무료가 쓰기 도구의 체크리스트를 누를 때 | [Plus 알아보기]는 P1, [괜찮아요]는 쓰기 그대로 |
| P8 고급 통계 | P6에서 Plus | 기분별 줄을 누르면 그 기분 일기 목록, 뒤로는 돌아보기 |

P8 상태: 불러오는 중(뼈대), 일기가 적음, 요즘 기분 세 가지, 좋은·힘든 기분 전환. Figma 섹션 "고급 통계 (P8)".

상태: 스토어 연결 실패(가격 자리에 다시 시도), 구매 진행 중(버튼 눌림), 구매 취소(그대로), 이미 있는 구매 복원(토스트).
