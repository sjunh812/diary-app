# 프로토타입: 광고와 Plus

Figma "화면" 페이지 섹션 "Plus와 광고 (P1~P7)". 문구의 원본은 코드의 문자열 리소스다.

| 화면 | 들어오는 길 | 나가는 길 |
| --- | --- | --- |
| P1 결제 화면 | 설정 Plus 줄, P3, 고급 통계 미리보기 | 닫기는 온 곳으로, 구매하면 P4 |
| P2 광고 제거 시트 | 광고 옆 "광고 없애기" | 구매 또는 닫기, 온 곳 그대로 |
| P3 사진 한도 시트 | 사진 11장째 | [Plus 알아보기]는 P1, [괜찮아요]는 쓰기 그대로 |
| P4 Plus 관리 | 이미 Plus일 때 설정 Plus 줄 | 스토어 구독 관리, 뒤로 |
| P5 홈 광고 자리 | 무료의 홈 목록 | 광고를 누르면 광고주 페이지 |
| P6 고급 통계 | 돌아보기. 무료는 미리보기 한 칸 | 미리보기를 누르면 P1 |
| P7 보상형 시트 | 광고 옆 "24시간 쉬기" | 영상을 보면 24시간 광고 없음 |

상태: 스토어 연결 실패(가격 자리에 다시 시도), 구매 진행 중(버튼 눌림), 구매 취소(그대로), 이미 있는 구매 복원(토스트).
