**작성**: 2026-11-27
**스펙**: [spec.md](../spec.md)

## 내용

- [x] 구현 방법보다 사용자가 얻는 것을 쓴다(날씨 서비스 이름은 헌법 II 개정에 묶인 결정이라 적음)
- [x] 사용자 요구(알리기, 가져오는 중 표시, 지우고 고치기, 군더더기 없는 설정)가 이야기마다 있다
- [x] 필수 절을 모두 채웠다

## 요구사항

- [x] [NEEDS CLARIFICATION] 표시가 없다. 처음 알리는 방법은 FR-002에서 프로토타입 시안으로 정한다고 적었다
- [x] 요구사항마다 시험할 수 있다
- [x] 성공 기준을 잴 수 있다
- [x] 엣지 케이스(회전, 백그라운드, 한도, 잠금, 태블릿)를 적었다
- [x] 범위가 정해져 있다(오늘 새 일기만, 빈 칸만, 기본 꺼짐)
- [x] 기대는 가정을 적었다(기상청 운영 한도, MET 트래픽)

## 헌법

- [x] I: 저장 형식·백업 형식이 바뀌지 않는다(`weatherAutoFilled`는 이미 있음, 설정은 기기에만)
- [x] II: 0.13.0 개정 범위 안이다. 좌표를 남기지 않는 시험(SC-003)이 있다
- [x] III: 무료
- [x] IV: 우리 서버 없음, 기기에서 바로 부름
- [x] VI: Android·iOS 같은 기능, 태블릿 두 칸 포함
