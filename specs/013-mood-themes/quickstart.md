# 확인 안내: 기분 15종과 기분 테마

명령은 `CLAUDE.md` "빌드와 시험"을 따른다. 설치는 에뮬레이터에만 하고, 한국어 화면을 먼저 본다.

## 1. 시험

```bash
./gradlew spotlessCheck designTokenCheck coroutineSafetyCheck stringResourceCheck unusedImportCheck detekt :composeApp:lint allTests assembleDebug
```

시험이 보는 것:

- 기분: id·레거시 번호 고정, 화면 순서 15칸 한 번씩, 묶음(US2-2)(`shared/core/model/src/commonTest`).
- 백업 번호: 새 기분 없음 → 드라이브 3·묶음 2, 휴지통에만 새 기분 → 4, 이 판은 4를 읽고 5를 막음, 드라이브 속성이 번호와 같음, 옛 백업(2·3) 복원(`shared/core/backup/src/commonTest`). 규칙은 [data-model.md](data-model.md) "백업 목록 파일".
- 설정: 저장·모르는 id 지키기, Plus 되돌리기(확정 전에는 지우지 않음, 클레이 꼴은 남김), 설정 백업 왕복(`shared/core/data`, `shared/app`의 `commonTest`).
- 그림: 그림 테마마다 15종이 라이트·다크·스티커 판까지 있고, 클레이는 머리 9가지마다 피부·머리·코·표정 겹이 있으며 쿨에는 안경을 겹치지 않음(`shared/core/ui/src/commonTest`의 `MoodArtTest`, `ClayLayersTest`). 그림이 칸 안 가운데에 놓였는지와 화질은 시험하지 않고 화면으로 본다(미검증 항목은 아래 2절).
- 화면(iOS 시뮬레이터): 쓰기 기분 시트 15칸, 테마 화면 고름·Plus 표시·미리보기 시트, 큰 글자에서 이름 두 줄.

## 2. 화면 (에뮬레이터, 한국어 먼저)

1. 새 일기 → 기분 칩 → 시트에 15칸이 네 묶음(5·5·2·3)과 묶음 이름으로 보이는지. 폰 세로에서 스크롤 없이 보이고, 작은 폰·큰 글자에서는 시트가 스크롤되는지. 설렘을 고르면 한 번 움직이고 들어가는지.
2. 저장 → 홈 목록·상세·달력·돌아보기·찾기(기분 거르기)에서 설렘 얼굴과 이름이 보이는지.
3. 돌아보기 → 고급 통계(개발자 모드에서 Plus) → 기준 시트에 15종이 세 묶음으로, 범례가 "쿨·보통·심심함"인지.
4. 설정 > 화면 > 기분 테마 → 도트를 고르고 홈·달력·돌아보기·쓰기 시트의 얼굴이 모두 바뀌는지. 앱을 껐다 켜도 남는지.
5. 개발자 모드에서 무료로 두고 클레이 얼굴을 누름 → 미리보기 시트에 그 테마의 15종이 보이고 테마는 그대로인지. [Plus 알아보기] → 결제 화면에 "기분 테마" 줄이 보이는지.
6. 개발자 모드에서 Plus로 바꾸고 클레이 얼굴 고름 → 머리·피부톤·안경을 바꿔 보고, 머리색이 기분마다 기분 색인지.
7. 개발자 모드에서 무료로 되돌림 → 기본 테마로 돌아가고, 다시 Plus로 바꿔 클레이를 고르면 고르던 꼴이 남아 있는지.
8. 다크, 글자 크기 최대, 태블릿 두 칸(쓰기 옆 칸, 설정 오른쪽 칸), 영어·일본어와 다섯 언어를 본다. 동작 줄이기를 켜면 움직이지 않는지.
9. 온보딩 그림과 결제 화면 그림의 기분 색이 새 15색인지.

## 3. 옛 앱과 백업 (`/backup-roundtrip`)

1. 이 빌드에서 옛 9종만 쓴 일기로 드라이브 백업 → 목록 파일 `formatVersion`이 3인지. 2.2.0 앱은 형식 2까지만 알아 형식 3도 이미 막는다.
2. 새 기분 일기를 하나 쓰고 백업 → 4인지. 그 일기를 휴지통에 넣고 백업해도 4인지.
3. 파일로 내보내기: 새 기분이 없으면 2이고 2.2.0 앱이 복원하는지, 있으면 4이고 2.2.0 앱이 "앱을 업데이트하면 복원할 수 있어요."로 막는지.
4. 새 기분과 클레이 테마가 든 백업을 무료 기기(이 빌드)에 복원 → 일기와 기분은 모두 들어오고 얼굴은 기본인지.

## 4. 업그레이드 (`/emulator-check`)

1.7.4와 2.2.0을 깔고 일기를 쓴 뒤 이 빌드를 덮어 깐다. 옛 기분이 모두 그대로이고 얼굴이 기본 테마 15종 판인지, 달력·통계 색이 새 15색인지 본다.

## 5. 성능과 크기

- 실기기 `benchmarkRelease`로 `StartupBenchmark`, `ScrollBenchmark`를 기본·클레이·질감 있는 테마에서 각각 돌려 중앙값과 느린 프레임 비율을 비교한다(SC-004).
- `apkanalyzer apk download-size`로 이 브랜치와 `develop`의 출시형 APK를 비교한다(+500KB 이하). iOS는 출시형 빌드의 앱 크기(+1MB 이하).
- 시작 경로나 쓰기 시트를 바꿨으므로 Baseline Profile을 다시 만든다(`/release-prep`).
