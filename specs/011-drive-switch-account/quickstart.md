# 확인 순서: 백업 구글 계정 변경

## 자동 시험

```bash
./gradlew :shared:core:backup:allTests :shared:feature:backup:allTests
```

- `BackupConnectTest`: 연결된 채 다른 계정 → 기록 지움·자동 백업 값 지킴·찾은 백업 권하기, 같은 계정 → 그대로, 취소·실패 → 이전 연결 그대로, 백업 중 → 바꾸지 않음(false), 바꾸는 동안 → 백업이 Busy
- 백업 설정 화면 시험(iosTest): [구글 계정] 줄에 이메일과 화살표, 누르면 바꾸기를 부른다

## 기기 확인 (`/backup-roundtrip`, `/emulator-check`)

구글 계정이 둘 있는 Android 에뮬레이터와 iOS 시뮬레이터에서 한국어부터 본다. 둘째 계정을 기기에 넣는 것(비밀번호 입력)은 사용자가 한다. 없으면 계정 하나로 1·4~8을 보고 2·3은 자동 시험으로 갈음한 것을 적는다.

1. 계정 A로 연결 → 첫 백업 끝남 → 드라이브 A의 스냅샷 수를 적는다.
2. 백업 설정 [구글 계정] 줄 → 계정 선택 창 → B. B에 백업이 없으면 첫 백업이 B에만 생긴다. A의 스냅샷 수는 그대로다.
3. 다시 [구글 계정] 줄 → A. A의 백업은 이 기기 것이라 합칠 것이 없어 묻지 않고 바로 백업한다(2026-11-08 "모두 0이면 권하지 않음"). 이 기기의 A 백업 기록은 B로 바꿀 때 지웠으므로 마지막 백업 시각은 새로 적힌다.
4. 백업이 도는 중 백업 설정에서 [구글 계정] 줄을 누른다 → 계정 선택 창 없이 "백업이나 복원이 끝나면 바꿀 수 있어요." 토스트.
5. [구글 계정] 줄 → 계정 선택 창에서 취소 → A 그대로, 안내 없음.
6. 비행기 모드에서 [구글 계정] 줄 → 실패 안내, A 그대로.
7. [연결 끊기] → [구글 드라이브 연결하기] → 계정 선택 창(10번 되풀이해 10번 뜬다).
8. 다크, 큰 글자, 태블릿(Pixel_Tablet) 두 칸에서 줄을 본다.
