# 화면 흐름: 의견 카드와 리뷰 창

**확정**: 2026-11-15(문구 A안, 아이콘 점 셋 말풍선, 백업 카드와 겹칠 때 안 A, 사용자 결정)

새 화면이 없다. 이미 있는 홈 목록에 카드 한 장이 붙고, 리뷰 창은 스토어가 그린다. 그래서 "표지 · 흐름"에 따로 프로토타입 섹션을 두지 않고, "화면" 페이지 "2 일기 > 홈 상태"에 상태 화면을 둔다.

| ID | 화면 | Figma |
| --- | --- | --- |
| S1-F | 홈 · 의견 카드(라이트) | 홈 상태 > `S1 · 의견 카드` |

| S1-F | 홈 · 의견 카드(태블릿 목록 칸) | 홈 상태 > `S1 · 의견 카드 · 태블릿` |

## US1 의견 카드

```text
홈 목록(3편·3일, 백업 카드 없음)
 ├─ [의견 보내기] → 브라우저로 설문 → 돌아오면 카드 없음
 └─ [닫기] → 카드 사라짐(다시 안 보임)
```

## 백업 카드와 겹칠 때(확정 안 A)

Figma "표지 · 흐름 > 프로토타입 · 의견 카드와 백업 카드", 흐름 시작점 "의견·백업 카드 · 안 A".

```text
홈 목록(백업 카드 조건과 의견 카드 조건이 함께 맞음)
 → 백업 카드만 보임
 → [나중에] → 그 자리에 의견 카드가 바로
 → [닫기] → 목록 보기 팁이 바로
```

안 B(맨 위 안내는 하루에 하나, 다음 안내는 다음 날)는 고르지 않았다. 하루씩 미루면 다음 안내가 너무 늦어진다(사용자 결정 2026-11-15).

## US2 리뷰 창

```text
쓰기 → 저장 → 상세 → 목록으로 돌아옴
 ├─ 전면 광고 차례(무료, 오늘 처음) → 전면 광고만
 └─ 차례 아님(오늘 이미 봄, 광고 없는 사용자) → 5편·7일·요청한 적 없음이면 스토어 리뷰 창 → 닫히면 목록 그대로
```
