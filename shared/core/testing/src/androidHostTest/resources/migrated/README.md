# 옮긴 결과 고정 자료 (스펙 001 FR-034)

1.7.4 → 2.0.0 기록 이전이 실제로 만든 결과다. 스펙 003(백업 v2)의 왕복 시험(백업 → 복원 → 같은지)이 이 자료에서 시작한다.

- 만든 법: API 36 에뮬레이터에서 `ALARM=0 sh scripts/legacy/upgrade-test.sh`(견본 `scripts/legacy/seed.sh`)를 돌린 뒤
  `databases/diary.db`와 `files/media/`를 그대로 꺼냈다(2026-11-01, 앱 2.0.0 (37), DB 버전 1).
- `diary.db`: 일기 4편, 사진 줄 4개(normal 3, missing 1). 1편은 사진 두 장(jpg, png 순서), 3편은 캐시에서 지워진 사진 자리,
  4편은 1편과 같은 jpg를 가리켜 파일은 하나다. 2편은 이모지와 잘못된 밀리초 날짜(`2024-10-30 23:59:457`)를 담는다.
- `media/<sha256>.<ext>`: 이름이 내용의 SHA-256이다. 줄임 사진(`thumbs/`)은 다시 만들 수 있어 넣지 않았다(백업에도 넣지 않는다).
- 일기 글은 시험용 견본이다. 실제 사용자 일기가 아니다.
